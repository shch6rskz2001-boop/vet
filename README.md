# Ветаптека Вітамінка

Інтернет-магазин товарів для тварин: ветеринарні препарати, амуніція, корми, іграшки, корми для гризунів і папуг, засоби гігієни, шампуні та консерви.

Живий сайт: https://shch6rskz2001-boop.github.io/vet/

## Про проєкт

Ветаптека Вітамінка дозволяє переглядати каталог, шукати й сортувати товари, фільтрувати їх за категоріями, переглядати сторінку товару, додавати його в кошик, реєструватись, входити в особистий кабінет та оформлювати замовлення.

## Технології

- Next.js 14 (App Router) + TypeScript
- Formik + Yup — усі форми
- React Context — кошик і авторизація
- CSS, адаптивна верстка (mobile first)
- GitHub Pages + GitHub Actions — деплой

## Сторінки

- `/` — головна з фотогалереєю
- `/catalog` — каталог з пошуком, фільтрами та сортуванням
- `/catalog/[id]` — сторінка товару
- `/cart` — кошик і оформлення замовлення
- `/register`, `/login` — реєстрація та вхід
- `/account` — особистий кабінет: дані профілю та історія замовлень
- `/contacts` — контакти та форма зв’язку

## Макет і ТЗ

Макета немає: це власний проєкт студента.

ТЗ:

- каталог із 8 категорій товарів, пошуком, сортуванням і фільтрацією;
- сторінка товару з описом і кнопкою додавання в кошик;
- кошик зі зміною кількості, видаленням і підрахунком суми;
- реєстрація та вхід з валідацією (Formik + Yup);
- особистий кабінет: редагування профілю та історія замовлень;
- оформлення замовлення лише для авторизованих, форма автозаповнюється даними профілю;
- неавторизованих користувачів із кабінету перенаправляє на сторінку входу;
- контакти магазину та форма зворотного зв’язку;
- адаптивна верстка для мобільних і планшетних пристроїв.

## Авторизація

Демо-реалізація без бекенду: користувачі, сесія й замовлення зберігаються в `localStorage`, паролі хешуються (SHA-256). Для production потрібен серверний бекенд.
