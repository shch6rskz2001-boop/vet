# Ветаптека Вітамінка — ветеринарна аптека та зоомагазин

Інтернет-магазин товарів для тварин: ветеринарні препарати, амуніція, корми, іграшки, корми для гризунів і папуг, засоби гігієни, шампуні та консерви.

## Про проєкт

Ветаптека Вітамінка дозволяє переглядати каталог, шукати й сортувати товари, фільтрувати їх за категоріями, переглядати сторінку товару, додавати його в кошик та оформлювати замовлення. Кошик зберігається в `localStorage`.

## Технології

- Next.js 14 (App Router) + TypeScript
- Formik + Yup — форми замовлення та зворотного зв’язку
- React Context — стан кошика
- CSS (адаптивна верстка, mobile first)

## Сторінки

- `/` — головна
- `/catalog` — каталог з пошуком, фільтрами та сортуванням
- `/catalog/[id]` — сторінка товару
- `/cart` — кошик і оформлення замовлення
- `/contacts` — контакти та форма зв’язку
